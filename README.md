# weby

Sbírka webů. Každý web má vlastní složku a vlastní Vercel projekt (Root Directory = složka webu).

| Složka | Web |
|---|---|
| `cerrado/` | CERRADO — výběrová pražírna (scroll web, fiktivní značka) |
| `vonavka/` | SPLENDOR — Noční kolekce, fiktivní parfémy (interaktivní stěna s flakony, Ateliér, Kontakt) |
